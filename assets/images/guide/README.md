# 사용 가이드 스크린샷 (assets/images/guide/)

사용 가이드(ankiGuide.html)에는 아래 6개 그림 자리가 미리 만들어져 있습니다.
**파일을 아래 이름 그대로 이 폴더에 넣기만 하면** 가이드에 바로 나타납니다.
파일이 없으면 그 자리는 자동으로 숨겨지므로, 한 장씩 천천히 채워도 괜찮습니다.

## 공통 권장 사항

- 형식: **PNG** (파일 이름은 아래 표와 글자 하나까지 똑같이, 모두 소문자)
- 크기: 가로 **1200~1600px** 정도 (PC 창은 Anki 창만 잘라서), 파일 하나에 **300KB 이하** 권장
- 폰 화면은 세로 그대로 캡처하면 됩니다 (가로 약 1080px).
- Anki는 **한국어 화면**, 밝은 테마(라이트 모드)로 캡처하면 가이드 글과 메뉴 이름이 잘 맞습니다.
- 내 계정 이메일, 다른 덱 이름 등 보이면 안 되는 정보는 가리거나 잘라 주세요.
- 예시 노트 유형 이름은 `다국어 단어장`, 필드는 `의미 · 단어 · 발음 · 예문 · 예문해석` 으로 맞추면 가이드 내용과 그대로 이어집니다.

## 파일을 바꾸거나 빼고 싶을 때

- 같은 이름으로 덮어쓰면 새 그림으로 바뀝니다. (브라우저에 예전 그림이 남아 있으면 새로고침 `Ctrl + F5`)
- 파일을 지우면 그 자리는 다시 자동으로 숨겨집니다.
- 그림 아래 설명 글은 `assets/i18n/<언어>/guide.js` 의 `guide.shot.*` 문구입니다.
