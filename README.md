# ⚡ Anki 다국어 카드 스크립트 에디터 (Anki Card Script Editor)

비개발자도 쉽고 빠르게 Anki 다국어 단어 카드 서식(앞면/뒷면/CSS)과 맞춤형 사전 검색 링크를 생성할 수 있는 웹 에디터입니다.  
별도의 설치나 백엔드 서버 없이 브라우저에서 단독으로 바로 동작합니다.

---

## 🌟 주요 기능

1. **46개 언어 공식 네이버 사전 링크 원클릭 매핑**
   - 영어, 일본어, 중국어부터 프랑스어, 스페인어, 독일어, 베트남어, 아랍어, 라틴어 등 46개 언어 완벽 지원
   - 언어 선택 시 해당 언어의 공식 네이버 사전 검색 링크가 자동 설정
   - 사전 검색 URL 직접 수정 및 커스텀 가능
2. **사전 링크 적용 위치 자유 선택**
   - 1번째 필드(단어), 2번째 필드(뜻), 3번째 필드(발음/예문) 중 원하는 필드에 바로 사전 링크 적용
   - 새 창(`target="_blank"`) 및 밑줄(`text-decoration`) 옵션 제어
3. **직관적인 글씨 크기, 색상, 굵기 커스텀**
   - 슬라이더 및 숫자 입력으로 폰트 크기(`font-size`) 실시간 조절
   - 컬러 피커 및 프리셋 팔레트로 색상(`color`) 변경
   - 보통(normal) / 굵게(bold) / 중간 굵게(600) 선택 시 실시간 코드 반영
4. **유연한 카드 앞면/뒷면 배치**
   - 1, 2, 3번째 필드를 앞면에 표시할지, 뒷면에 표시할지 체크박스로 각각 선택
   - 뒷면에 앞면 내용 유지 및 `<hr id="answer">` 구분선 표시 여부 지원
5. **실시간 Anki 카드 시뮬레이터 (미리보기)**
   - 앞면/뒷면 전환 및 카드 뒤집기(🔄) 시뮬레이션
   - 실제 단어 클릭 시 사전 검색 페이지 새 창 이동 테스트 가능
   - 다크모드(🌙) 미리보기 지원
6. **원클릭 클립보드 복사**
   - 앞면 서식, 뒷면 서식, CSS 스타일을 버튼 한 번으로 클립보드에 복사

## 💻 실행 방법 (How to Run)

### 방법 1: 가장 간단한 방법 (더블 클릭 실행)
별도의 프로그램 설치나 터미널 실행 없이 바로 사용할 수 있습니다.
1. 본 폴더에 있는 **`index.html`**(메인 도구 메뉴) 또는 **`ankiEditor.html`**(Anki 에디터) 파일을 더블 클릭합니다.
2. 기본 웹 브라우저(Chrome, Edge, Whale, Safari 등)에서 즉시 실행됩니다.

---

### 방법 2: 웹 주소 (GitHub Pages) 접속
GitHub Pages에 배포 시 다음과 같이 접속할 수 있습니다:
* **메인 도구 허브 (Menu)**: `https://<아이디>.github.io/LanguageStudy/`
* **Anki 에디터 직접 접속**: `https://<아이디>.github.io/LanguageStudy/ankiEditor`

---

### 방법 3: 로컬 개발 서버로 실행하기 (선택 사항)
- **VS Code 사용 시**: `Live Server` 확장 설치 후 `index.html` 우클릭 → **Open with Live Server**
- **Python 사용 시**: `python -m http.server 8000` 실행 후 브라우저에서 `http://localhost:8000` 접속
- **Node.js 사용 시**: `npx serve` 실행 후 접속

---

## 📖 Anki 카드에 적용하는 순서

1. **설정하기**: 에디터에서 학습할 언어와 본인 카드의 필드명(예: `Front`, `Back`, `pinyin` 등)을 입력합니다.
2. **스타일 조절**: 글씨 크기, 색상, 굵기 및 사전 링크 적용 필드를 원하는 대로 설정합니다.
3. **미리보기 확인**: 우측 카드 시뮬레이터에서 카드를 뒤집어보고 단어를 클릭하여 사전이 잘 열리는지 테스트합니다.
4. **코드 복사**: 우측 하단에서 **[앞면 서식 복사]** 및 **[뒷면 서식 복사]** 버튼을 누릅니다.
5. **Anki에 붙여넣기**: Anki 실행 → [카드 추가] 또는 [탐색] 창에서 **[카드...]** 버튼을 누른 후 앞면/뒷면 서식란에 각각 붙여넣으면 완료됩니다.
